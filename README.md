# Denmark Delights

I need a website for a restaurant which consists of the restaurants menu from which if the customer  orders the items from this website it much reach the server of the owner, it must notify the owners about the order . The restaurant name is "DENMARK RESTAURANT" which must printed in the front page of the website. The main theme is to provide authentic non vegetarian foods,  in chinese and arabian format in a state like Tamil nadu.  So add some 3d videos and pictures according to this theme and give me nearly 100 buttons to add the dishes and its price.  In simple words I need a website which  contains the menu and can be ordered by the customers.  At the end of the ordering process it must contain 2options "DINE IN and DELIVERY" which notifies  that the cutomer is interested in dining or take away the order.   After the dining and delivery process , there must be payment details that contains credit cards, debit cards, all form of net bankings and also cash on delivery  options from which the bank details of the owner of the server can be edited only by the owner. The menu must only be edited by the main server.  In this website there must be no visibility about the owner bank details and strictly every informations should only be modified by the main server ie the owner. The customers should only have the visibilities of restaurant details, items to order, total, payment options and the dining options.
